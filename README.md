# Clipboard Vibe

> 一个现代化的剪贴板历史管理器，支持文字、文件、AI Token 余额查询和模拟打字，让复制粘贴更高效。

  <img src="build/icon.png" alt="Clipboard Vibe" width="128" height="128" />
</p>

## 它解决什么问题？

Windows 自带的剪贴板只能保存**最后一条**内容。当你需要：

- 在多个文档之间来回复制粘贴文字
- 找回之前复制过但被覆盖的文件
- 收藏常用的代码片段或模板文件
- 跨窗口快速调用历史内容
- 同时管理多个 AI 平台的 API Key 余额
- 在禁止粘贴的网站/应用中自动输入文字

Clipboard Vibe 会在后台自动记录所有复制过的**文字**和**文件**，通过全局快捷键一键唤出，搜索、选择、粘贴一气呵成。还内置了 Token 余额查询面板和自动打字工具，一站式提升效率。所有数据保存在本地，不上传任何服务器。

## 主要功能

### 📋 剪贴板历史
- 自动捕获所有复制的**文字**和**文件**
- 文字最多保存 200 条（可在 10 ~ 1000 之间调整）
- 文件最多保存 100 个（可在 1 ~ 500 之间调整）
- 复制相同内容会自动置顶，不会重复存储

### 📁 文件剪贴板
- 自动保存复制的文件副本，原始文件删除后仍可找回
- 按文件类型显示不同图标（图片 / 文档 / 压缩包 / 音视频 / 代码等）
- 显示文件名、文件大小、复制时间
- 点击复制到剪贴板，可直接粘贴到任意位置
- 支持直接打开文件 / 在文件夹中显示
- 可自定义文件存储位置，支持迁移已有文件

### 💰 Token 余额查询
- 支持 **5 个 AI 平台**：Kimi、DeepSeek、智谱 AI、阿里云百炼、腾讯云混元
- **本地加密存储** API Key（AES-256 + 机器指纹）
- 实时刷新余额，总览面板一目了然
- 支持添加标签备注，方便区分多个 Key
- 一键跳转到各平台充值页面
- 托盘菜单快速打开 Token 余额面板

### ⌨️ 自动打字
- 模拟键盘输入，绕过学习通等网站的复制粘贴限制
- 支持**中英文直接输入**，无需切换输入法
- 可调节启动延迟（0~60 秒），留出时间切换到目标窗口
- 四档速度预设：慢 / 中 / 快 / 极速，也可自定义间隔
- 实时进度显示，随时紧急停止
- 一键填入剪贴板最新文本

### ⚡ 全局快捷键
- 默认 `Ctrl + Shift + V` 唤出窗口
- 支持自定义任意组合键，录制式设置
- 设置后立即生效，无需重启

### ⭐ 收藏夹
- 文字和文件都可以收藏
- 收藏的内容**独立存储**，不受历史数量限制
- 在历史中删除收藏项，收藏夹里仍然保留
- 清空历史不会删除收藏内容

### 🔍 搜索与导航
- 实时搜索，输入关键词即时过滤
- 支持键盘导航：`↑↓` 选择、`Enter` 粘贴、`Esc` 关闭、`Delete` 删除
- 多标签页切换：全部 / 文字 / 文件 / Token / 打字 / 收藏 / 设置

### 🔔 系统托盘
- 托盘图标常驻，点击唤出窗口
- 右键菜单：显示剪贴板、Token 余额、清空历史、退出
- 窗口失去焦点自动隐藏
- 窗口跟随光标位置弹出

### 🎨 玻璃质感 UI
- 毛玻璃效果 + 深色主题
- 无边框透明窗口
- 可调整窗口大小

## 从源码构建

如果你想自己编译或参与开发，可以从源码构建。

### 环境要求

- Node.js >= 18
- Windows 系统（使用了 Windows 剪贴板 API）

### 步骤

1. **克隆项目**

   ```bash
   git clone https://github.com/fan-x007/Clipboard.git
   cd Clipboard
   ```

2. **安装依赖**

   ```bash
   npm install
   ```

3. **开发模式运行**

   ```bash
   npm run electron:dev
   ```

4. **打包成安装包**

   ```bash
   npm run dist:win
   ```

   打包完成后，安装包会输出到 `release/` 目录。

## 使用方法

### 1. 唤出窗口

按下全局快捷键 **`Ctrl + Shift + V`**，窗口会出现在光标附近。

> 💡 快捷键可以在「设置」中自定义。也可以点击系统托盘图标唤出。

### 2. 标签页说明

| 标签 | 说明 |
|------|------|
| 全部 | 显示所有历史记录（文字 + 文件） |
| 文字 | 只显示文字剪贴历史 |
| 文件 | 只显示文件剪贴历史 |
| 💰 Token | AI 平台 Token 余额管理 |
| ⌨️ 打字 | 自动打字工具，绕过粘贴限制 |
| ⭐ 收藏 | 显示所有收藏的内容 |
| ⚙️ 设置 | 调整快捷键、存储数量、文件存储位置等 |

### 3. 复制文字

1. 在任意地方按 `Ctrl + C` 复制文字
2. 按快捷键唤出窗口，文字自动出现在列表顶部
3. 点击条目或按 `Enter` → 文字写回剪贴板，窗口关闭
4. 到目标位置按 `Ctrl + V` 粘贴

### 4. 复制文件

1. 在文件资源管理器中选中文件，按 `Ctrl + C`
2. 按快捷键唤出窗口，切换到「文件」标签
3. 点击文件项 → 文件写回剪贴板，窗口关闭
4. 到目标文件夹按 `Ctrl + V` 粘贴

文件项上还有两个快捷按钮：
- 📂 **打开文件** — 直接用默认程序打开
- 📁 **打开位置** — 在文件夹中显示该文件

### 5. 查询 Token 余额

1. 唤出窗口，切换到「💰 Token」标签
2. 选择平台（Kimi / DeepSeek / 智谱 / 百炼 / 腾讯云）
3. 输入 API Key 和标签，点击「添加」
4. 余额自动刷新，总览面板显示总余额
5. 点击「🔄」刷新单个平台，点击「刷新全部」批量更新

> 🔒 所有 API Key 在本地使用 AES-256 加密存储，结合机器指纹保护，不会上传到任何服务器。

### 6. 使用自动打字

1. 唤出窗口，切换到「⌨️ 打字」标签
2. 粘贴或输入要打的文字
3. 设置启动延迟（秒）和打字间隔（毫秒/字）
4. 点击「▶ 开始打字」
5. **立即切换到目标输入框**，等待倒计时结束后自动开始输入

> 💡 基于 .NET SendKeys 实现，支持中英文直接输入，兼容绝大多数应用和网站。
>
> ⚠️ 打字进行中请勿操作鼠标键盘。如需紧急停止，点击「停止」按钮。

### 7. 搜索

直接输入文字，列表会实时过滤匹配的内容（文字内容和文件名都会匹配）。

### 8. 收藏

鼠标悬停在条目上，点击 ⭐ 按钮加入收藏。收藏的内容：
- 不会被自动清理
- 从历史删除后仍保留在收藏夹中
- 清空历史不受影响

在「收藏」标签中：
- 再次点击 ⭐ 可取消收藏（内容还在历史里）
- 点击 🗑️ 可彻底删除收藏项

### 9. 删除

- 选中条目后按 `Delete` 或 `Backspace` 删除单条
- 点击右上角 🗑️ 按钮清空当前标签页内容
  - 在「全部 / 文字 / 文件」标签：清空历史，**收藏保留**
  - 在「收藏」标签：**彻底删除**所有收藏内容

### 10. 设置

切换到「⚙️ 设置」标签页，可以：

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 全局快捷键 | 录制式设置，按下任意组合键即可 | `Ctrl + Shift + V` |
| 最大文字条数 | 10 ~ 1000 条 | 200 |
| 最大文件数 | 1 ~ 500 个 | 100 |
| 文件存储位置 | 自定义文件副本保存目录，支持迁移 | `AppData\clipboard-files` |
| 恢复默认设置 | 一键还原所有设置为默认值 | — |

## 数据存储位置

所有数据保存在本地，不上传任何服务器：

| 数据 | 路径 |
|------|------|
| 剪贴板历史（JSON） | `%APPDATA%\clipboard-vibe\clipboard-history.json` |
| 文件副本 | `%APPDATA%\clipboard-vibe\clipboard-files\`（可自定义） |
| 设置配置 | `%APPDATA%\clipboard-vibe\settings.json` |
| Token Key（加密） | `%APPDATA%\clipboard-vibe\token-keys.enc.json` |

## 技术栈

- **Electron 31** — 桌面应用框架
- **React 18** — UI 框架
- **TypeScript** — 类型安全
- **Vite 5** — 构建工具
- **electron-builder** — 打包发布
- **.NET SendKeys** — 模拟键盘输入引擎
